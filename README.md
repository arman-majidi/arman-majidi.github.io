# Arman Majidi — Academic Homepage

Personal academic website for **Arman Majidi** (M.Sc. Student in Electrical Engineering at Sharif University of Technology), built with clean, dependency-free HTML, CSS, and JavaScript.

## Structure

- `index.html`: Main page structure and academic biography.
- `styles.css`: Two-column academic sidebar layout (inspired by AcademicPages) with light and dark mode support.
- `app.js`: Theme toggle, mobile navigation, active section highlighting, and email copy helper.
- `theme.js`: Applies the saved color scheme before first paint.
- `assets/portrait.jpg`: Optimized profile portrait.
- `assets/Arman_Majidi_CV.pdf`: Curriculum Vitae (PDF).
- `assets/*.svg`: Tool and profile icons.
- `GITHUB_PAGES_FA.md`: Step-by-step Persian guide for publishing on GitHub Pages.
