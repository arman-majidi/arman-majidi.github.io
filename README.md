# Arman Majidi: personal academic website

Static site (HTML, CSS, vanilla JS) published at https://arman-majidi.github.io/. No build step or dependencies.

- `index.html`: content, semantic sections, and metadata
- `styles.css`: layout, light/dark themes, responsive and print rules
- `app.js`, `theme.js`: navigation, scroll progress, section reveal, theme toggle, copy-email button
- `signals.js`: interactive hero wave, blind speech separation audio/STFT/ICA lab (Fig. 01), and 3D accelerometer/CNN window sketch (Fig. 02)
- `assets/`: portrait, CV, icons, social preview image

Update by editing the files and pushing to `main`; GitHub Pages serves the root.

Fonts: Inter (SIL OFL 1.1, self-hosted subset in `assets/fonts/`) for body text; Newsreader for headings and JetBrains Mono for technical labels.
