# Arman Majidi: personal academic website

Static site (HTML, CSS, vanilla JS) published at https://arman-majidi.github.io/. No build step or dependencies.

- `index.html`: content and metadata
- `styles.css`: layout, light/dark themes, responsive rules
- `app.js`, `theme.js`: navigation, theme toggle, copy-email button
- `signals.js`: the two synthetic research illustrations (not experimental data)
- `assets/`: portrait, CV, icons, social preview image

Update by editing the files and pushing to `main`; GitHub Pages serves the root.

Fonts: Inter (SIL OFL 1.1, self-hosted subset in `assets/fonts/`) for text; headings use a system serif stack (Iowan Old Style / Palatino / Georgia).
